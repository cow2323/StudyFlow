# Intro
Studyflow is a booking system for students. Log in make a new user and view and book rooms.



## Basic Info 

Currently under production and development: We have created three test users using the format "user1@users.com" - "user3@users.com" and password "Password123!".
We can currently book up to ten different rooms


## Build info & Running 
Built in .NET CORE 10.0.400

The system will run using terminal command ```dotnet run ``` from terminal in a C# ASP.NET compatible system.
